# LibreOffice headless open check

Both exported workbooks were opened by LibreOffice 24.2.7.2 420(Build:2).
The command exits 0 and the only stderr line is the headless javaldx warning.
There is no document-recovery message. The formula LEN(A2) calculates to 28,
which is the length of "Do you encrypt data at rest?", so the file was opened
and recalculated. The answer cell is the literal text Approved. The percent
format on 100 is displayed by Calc as 10000%.

Command:

    soffice --headless --norestore --convert-to csv --outdir OUT FILE.xlsx
