---

Build a lightweight, signed agent that employees install. It reports:

* disk encryption
* screen lock
* OS update status
* firewall
* antivirus or EDR present
* password manager present

It collects no personal files, browsing data or keystrokes, and its privacy notice is shown to employees. MDM integrations (Jamf, Intune) are out of scope (scope-freeze §7) and need a separate decision.

**Done when:** device posture shows per employee, and non-compliant devices raise alerts.
