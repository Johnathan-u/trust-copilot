Let a workspace connect Google Drive and choose folders. TrustCopilot imports Google Docs, Sheets, PDFs and Word files from them as evidence, detects new or changed files, re-indexes them, and cites the document and version in answers. This matches Orbiq's Drive sync.

**Build on:**

* `connector_wizard_service.py` and `source_registry_service.py` (connection setup)
* the credential store (encrypted tokens)
* `ingestion_pipeline_service.py` and `evidence_parser.py` (parsing and indexing)

**Requirements:**

* Read-only access to selected folders only. Check Google's OAuth scope rules first: broad Drive read scopes need Google app verification and a security assessment. Prefer the narrowest scope (for example, the Drive file picker).
* Export Google Docs and Sheets to text.
* Detect changes, with retry and rate-limit handling.
* Data stays within the workspace.
* Disconnecting deletes tokens and stops syncing.

**Out of scope today:** new connectors need owner approval (TC-32-011) before agents start.

**Done when:** a connected folder's files appear as evidence within 15 minutes of a change, answers cite the Drive document, and cross-workspace negative tests pass.
