**Goal:** Prove that one MSP's clients can never see each other's data, and that MSPs can't see each other.

**Acceptance criteria**

1. Extend the endpoint-by-role-by-tenant matrix (TC-06-005) with MSP admin, MSP analyst and client-user principals.
2. Cover: client A user reading client B objects by ID, MSP 1 staff reading MSP 2 clients, analyst not assigned to a client, removed staff with an old cookie, exports, downloads, search and cached results.
3. Every case returns the same not-found/denied response with no data leakage in errors or counts.
4. Suite runs in CI and fails the build on any leak.

**Definition of done:** suite passes in CI; an independent reviewer signs off; any leak found is fixed or filed as P0.\
Workflow: see SCRUM-35.
