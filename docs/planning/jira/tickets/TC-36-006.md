**Goal:** An MSP can see exactly what it will pay without booking a call. That is the opposite of suite pricing, which goes through procurement.

**Acceptance criteria**

1. `/pricing` shows the MSP plan: base fee, included clients, per-extra-client fee, annual option, trial terms. Prices come from one config file that matches the Stripe price IDs (TC-35-012), so they can't drift.
2. A worked example: "10 clients = $X/month" computed from the config, not hard-coded.
3. A short "questionnaire-first, not a compliance suite" section listing what is and isn't included. No named-competitor price claims.
4. Main button "Start free trial" goes to self-serve signup (TC-36-008). The secondary link is "Talk to us".
5. Page passes the marketing site's SEO and accessibility checks and works at 360 / 768 / 1440 px.

**Definition of done:** Playwright spec passes, including a check that displayed prices equal the config values. Reviewed by a second person.\
Workflow: see SCRUM-35.
