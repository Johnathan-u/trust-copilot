Manage policies through their lifecycle:

* version history with diffs
* a named owner and an approver for each policy
* an approval workflow with an audit trail
* review reminders, annually by default, through E19 notifications
* policies feed answer generation as evidence and can be published to the trust center (TC-17-002)

**Done when:** an auditor can see each policy's approved version, approver, date and review history.
