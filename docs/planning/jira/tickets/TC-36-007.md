**Goal:** Let an MSP owner see the payback in 10 seconds, so the price is an easy yes.

**Acceptance criteria**

1. Inputs: number of clients, questionnaires per client per month, hours per questionnaire today (default 6), hourly rate (default $75).
2. Outputs: hours saved per month (using a stated assumption, default 70% time saved, which the user can edit), money saved, TrustCopilot monthly cost (from the pricing config), and payback shown as "pays for itself after N questionnaires".
3. Every assumption is visible and editable. No hidden multipliers.
4. Works without JavaScript errors at 360 / 768 / 1440 px and by keyboard. Results update as you type.
5. Unit test for the math with at least 4 fixed cases, including 0 clients and very large inputs.

**Definition of done:** Playwright and unit tests pass. Reviewed by a second person.\
Workflow: see SCRUM-35.
