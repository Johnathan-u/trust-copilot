**Goal:** Everything a client sends out carries the MSP's brand, not TrustCopilot's.

**Acceptance criteria**

1. PDF summaries and evidence-pack cover pages use the MSP's logo, name and color.
2. Exported XLSX workbooks keep the customer's original layout untouched (E13 fidelity rules); branding only appears in added cover/notes sheets, if enabled.
3. File names and document metadata (author, producer) use the MSP name.
4. Clients of an MSP without branding get neutral exports.

**Definition of done:** tests pass, including a check that the original workbook cells are unchanged; reviewed by a second person.\
Workflow: see SCRUM-35.
