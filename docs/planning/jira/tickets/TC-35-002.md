**Goal:** MSP admins can add a new client company, invite that client's own users, and offboard a client cleanly.

**Acceptance criteria**

1. MSP admin creates a client workspace with name, primary contact and frameworks; it is owned by the MSP organization.
2. MSP admin invites client users with client roles (viewer, reviewer, editor); invites use the existing single-use token flow.
3. Offboarding a client offers: transfer the workspace to the client as a standalone account, export all data, or delete per the retention rules (E08).
4. Client limits from the MSP's plan are enforced at creation (TC-35-013).

**Definition of done:** tests pass in CI including permission negatives; UI states for loading, error and limit reached; reviewed by a second person.\
Workflow: see SCRUM-35.
