**Goal:** The bill always matches the number of active client workspaces.

**Acceptance criteria**

1. Adding or offboarding a client updates the Stripe subscription quantity with proration.
2. Invoices list the base plan and the client-workspace line with the count.
3. Creating a client beyond the plan limit is blocked with an upgrade prompt (uses TC-24-004 limits).
4. A nightly reconciliation compares active client workspaces with Stripe quantities and alerts on any mismatch.

**Definition of done:** tests pass in Stripe test mode including retries and duplicate webhooks; reviewed by a second person.\
Workflow: see SCRUM-35.
