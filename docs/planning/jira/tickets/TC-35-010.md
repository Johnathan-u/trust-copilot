**Goal:** When a client's questionnaire is generated, matching MSP template answers are used first, with the source shown.

**Acceptance criteria**

1. Generation checks the client's approved answers, then the MSP template library, then the client's evidence documents, in that order.
2. Each answer shows where it came from (client answer, MSP template version, or cited document), using the citation rules of E11.
3. Template-based answers still go through human review before export; nothing is auto-approved.
4. Measured on a test set: share of questions answered from templates is reported per run.

**Definition of done:** tests pass; source labels visible in the review screen; reviewed by a second person.\
Workflow: see SCRUM-35.
