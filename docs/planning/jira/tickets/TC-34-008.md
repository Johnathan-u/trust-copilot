For new hires, check that policies are accepted, training is done and the device agent is installed by their deadlines.

For leavers, use E20 connectors to verify their accounts are disabled in Google Workspace, Okta, GitHub, GitLab and the cloud providers within a set window (24 hours by default). Flag misses as alerts through E22.

**Done when:** a test leaver whose GitHub access isn't removed produces an alert, and clearing it is audited.
