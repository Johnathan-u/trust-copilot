**Goal:** The MSP does all the work for a client. The client does not have to create an account, accept anything or switch a feature on. With Vanta, by contrast, each client has to switch on questionnaire automation in its own account.

**Acceptance criteria**

1. An MSP admin can create a client workspace with zero client users. It is fully usable: upload, generate, review, approve and export.
2. Every action the MSP takes inside a client workspace is written to that client's audit log with the MSP user's name and "acting for <client>".
3. Inviting client users is optional and can happen any time later. Invited users see everything done so far.
4. A client workspace with no client users counts as an active client for billing (TC-35-013).
5. No path lets one MSP see another MSP's clients. The test covers two MSPs with similar client names.

**Definition of done:** tests pass, including the audit-log and two-MSP isolation cases. Reviewed by a second person.\
Workflow: see SCRUM-35.
