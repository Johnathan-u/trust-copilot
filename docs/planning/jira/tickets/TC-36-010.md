**Goal:** When a client user signs in to review or approve answers, every screen they see carries the MSP's brand.

**Acceptance criteria**

1. Each MSP gets a portal path or subdomain (e.g. `app.<host>/p/<msp-slug>`). Login, password reset, review, approval and export download pages there show the MSP's logo, colors and name.
2. Browser tab title and favicon use the MSP name and logo. There is no "TrustCopilot" in visible text, page titles, meta tags or alt text for client users.
3. Client users see only their own workspace and only the actions they are allowed (review, comment, approve). No MSP-level navigation.
4. When the custom domain from TC-35-008 is set, the same portal is served on it with no visible redirect to the TrustCopilot host.
5. Colors are checked for contrast. If the MSP's brand color fails WCAG AA for text, the portal uses a safe variant automatically.
6. Works at 360 / 768 / 1440 px and by keyboard.

**Definition of done:** Playwright spec passes for a branded and an unbranded MSP. The accessibility check has no serious violations. Reviewed by a second person.\
Workflow: see SCRUM-35.
