Let a workspace connect Confluence Cloud and choose spaces or page trees. TrustCopilot imports pages and attachments as evidence, detects edits, re-indexes them, and cites the page and version in answers. This matches Orbiq's Confluence sync.

**Build on:** the same connector, credential store and ingestion pipeline as TC-32-013. Ship TC-32-013 first so both share one sync design.

**Requirements:**

* Atlassian OAuth 2.0 with read-only scopes.
* Respect page permissions as the connecting user sees them.
* Detect changes by polling or webhooks, with rate-limit handling.
* Data stays within the workspace.
* Disconnecting deletes tokens.

**Out of scope today:** new connectors need owner approval (TC-32-011).

**Done when:** pages in a connected space appear as evidence within 15 minutes of an edit, answers cite the Confluence page, and cross-workspace negative tests pass.
