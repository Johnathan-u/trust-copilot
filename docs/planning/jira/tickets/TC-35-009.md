**Goal:** MSPs write their 'standard stack' answers once (backups, endpoint protection, MFA, patching) and reuse them for every client.

**Acceptance criteria**

1. MSP-level answer library with versioned answers, tags and framework mappings (builds on the golden answer library, TC-12-005).
2. Answers support variables such as {client_name}, {backup_frequency}, filled from each client's profile.
3. Each client can override a template answer; the override is kept when the template changes, and the client sees that a newer template version exists.
4. Template text is never shown to clients of a different MSP.

**Definition of done:** tests pass including override and version cases; reviewed by a second person.\
Workflow: see SCRUM-35.
