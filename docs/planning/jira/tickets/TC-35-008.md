**Goal:** Each client's public trust page can live on the MSP's domain (for example trust.client-name.msp.com) with the MSP's branding.

**Acceptance criteria**

1. MSP admin adds a custom domain; the app shows the DNS record to add and verifies it before going live.
2. TLS certificates are issued and renewed automatically; expiry is monitored (TC-27-008).
3. The trust page shows the MSP's branding and only the client's published content (E17 rules).
4. A domain cannot be claimed by two MSPs; removing a domain stops serving it immediately.

**Needs the owner:** a real domain and DNS access to test end to end.

**Definition of done:** tests pass; a real custom domain verified in staging; reviewed by a second person.\
Workflow: see SCRUM-35.
