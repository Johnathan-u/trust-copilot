## Problem

Create stores `article_ids`, `answer_ids`, and `document_ids` without checking that each id is in the space's workspace (`shareable_space_service.py:81-83`). Access returns those lists without the same check (`:143-145`). The lists do not gate original downloads. `GET /api/documents/{id}/content` requires a reviewer session and does not read the share token.

## Acceptance criteria

1. On create and on access, reject an article, answer, or document id that is not in the space's workspace.
2. Limit a token download to the listed objects. A change to the list, expiry, or active flag makes the previous download fail.
3. Document the behaviour in this file.
