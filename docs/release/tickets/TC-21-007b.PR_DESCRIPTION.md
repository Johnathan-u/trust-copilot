## Ambiguity

A recommendation can have no live source: the gap title is stored, but its question was deleted, its control is in another workspace, or its evidence ids are foreign or tied to a deleted document. That row is kept, with empty `evidence_ids`, `control_ids`, and `question_ids`. Dropping it would remove `title` and `improves_questions`. `improves_questions` stays the open-gap count and is not rewritten to the length of `question_ids`.

## Field shape

```text
{
  "title": "...",
  "improves_questions": 1,
  "evidence_ids": [],
  "control_ids": [],
  "question_ids": []
}
```
