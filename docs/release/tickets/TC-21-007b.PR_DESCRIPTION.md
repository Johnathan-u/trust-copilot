## AC6

| Item | Test |
| --- | --- |
| A sourced recommendation includes the live evidence id, control id, and question id | `test_recommendations_carry_live_same_workspace_ids` |
| A foreign control id and a foreign or deleted evidence id are omitted | Same test, the dropped title |
| A question on a deleted questionnaire is omitted | Same test, the dropped title |
| A recommendation with no stored source has empty lists | Same test, the sourceless title |
| A fallback recommendation uses the stored insufficient question and no invented evidence or control id | `test_inferred_recommendation_uses_the_stored_question` |
| GET does not write | Same first test: row counts and `updated_at` are unchanged |
| The web consumer reads the three id lists and treats a missing list as empty | `coverageConsumer.test.ts` |
