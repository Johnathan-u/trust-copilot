# TC-14-006b — Drawer and dialog focus and live-region follow-ups

## Behavior

The polite toast region and the assertive toast region stay outside `inertOutside`. A dialog or the navigation drawer can be open while those regions keep `aria-live` and stay in the accessibility tree.

When the viewport crosses 768px with the mobile drawer open, the drawer closes. Focus returns to the trigger when that control is visible and focusable. When the compact menu button is hidden at the docked width, focus moves to the main landmark, or to the first link in the docked sidebar if the main landmark cannot take focus.

Drawer panels use `min(20rem, calc(100% - 2.75rem))` and `shrink-0`. The content wrapper is `min-w-0 max-w-full` and does not use `flex-1`, so it does not cover the backdrop. At 320px and below, the strip beside the drawer still receives a tap and dismisses the drawer.
