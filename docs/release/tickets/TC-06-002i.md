# TC-06-002i — Export-worker parent and replay authorization

Parent: TC-06-002. Estimate: 3 child points; zero additional original-scope credit.
Claim: issue #85 comment 6533395283. Base: `dea5f5afe87dfa73a0321a0f0311847ed233432f`.

## Scope and root cause

`run_export` scopes its questionnaire and artifact by payload workspace while quota
and effect records use the persisted job workspace. It also accepts archived
questionnaires and reuses any same-workspace export record linked to the job,
without matching the questionnaire. Persisted SQLite intake reproduced a foreign
answer rendered into an artifact while a different workspace was charged.

Only `apps/api/app/worker.py`, this child's new release tests, ticket and acceptance
evidence are owned. Queue lifecycle, shared authentication, schema, enqueue routes,
job actions, artifact API projection and unrelated handlers remain outside scope.

## Implementation plan

1. Add failing persisted SQLite and migrated PostgreSQL counterparts using actual
   model constraints, dispatch, renderers, quota/effect ledger and commits. Replace
   only object-storage I/O with an in-memory boundary; use no real providers.
2. Reject invalid reference shapes and require agreement between the current job,
   payload and current active questionnaire before quota, storage, artifact or replay
   effects. A job-linked replay record must match that tenant and questionnaire.
3. Preserve valid export/replay and storage-failure behavior. Check every column of
   source and effect rows, absence of DML for denied execution, exact changed rows
   for own success, and primary-key-scoped cleanup back to the fixture baseline.
4. Run focused and related regression, collection and lint checks. Keep real
   PostgreSQL and exact-head push/PR CI as mandatory gates when unavailable locally.
   Return a clean local commit for independent review; the coordinator publishes.

## Reference contract

The enqueue service emits positive JSON integer workspace/questionnaire IDs.
Booleans, floats, strings, containers, missing/nonpositive/out-of-range IDs are not
coerced into authority. Invalid or unavailable references fail with a neutral
terminal input error. Original-parent acceptance remains pending.
