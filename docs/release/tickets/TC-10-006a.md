## Problem

A recorded export hash must match the object or the download is refused. Question rows store content and file hashes. An export with no recorded hash still downloads, and document rows have no hash column. Priority is P1 because the parent is P1.

## Acceptance criteria

1. Store a hash for the document object and for the export record, and make the record and the object agree on hash, version, type, and workspace.
2. Refuse the download when the recorded hash is missing or does not match, and do not stream an export that has no recorded hash.
3. Document the behaviour in this file.
