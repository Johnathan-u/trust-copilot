# TC-04-007 Bound identity abuse and account enumeration

Epic E04. P0. Not accepted. Not counted toward DONE.

The planning ticket stays the backlog entry. This file records the behaviour after the children. It does not accept TC-04-007, TC-04-007a, or TC-04-007b.

## Behaviour

**Enumeration (TC-04-007a, merged in #316).** `POST /api/auth/forgot-password` refuses when `reset:ip` is already at the cap, records the attempt, then loads the user. A known address and an unknown address return the same generic 200 body ten times, then the same 429 body. The route has an IP key only. Production does not return `reset_url`.

**Shared limiter (TC-04-007b).** Login, reset, resend, and invite throttles use one store across processes. `REDIS_URL` selects Redis. When it is unset, the counts are rows in `rate_limit_buckets`. The window is fixed: the first attempt starts it, later attempts inside it increment, and an attempt after `window_sec` starts again at 1. A second process on the same database sees the count.

429 responses for login, forgot-password, reset-password, resend-verification, invite verification, and invite creation send `Retry-After` (whole seconds, at least 1, at most the window). The body text is unchanged.

Invite creation allows 10 new invites per 60 seconds for the acting user and for the workspace. The eleventh is 429 `Too many invites. Try again later.` and inserts no row. Invalid emails, existing members, and duplicate invites do not consume that window.

The caps that were already enforced stay: login and reset are 10 in 60 seconds, resend is 3 then 429 inside 900 seconds, invite verification is 10 failures then 429 inside 900 seconds. A login window does not block the reset route. There is no permanent lock column on this path. A later window starts at 1, so a lockout cannot permanently disable owner recovery.

Store errors fail open, except `POST /api/workspaces` in production, which still fails closed. The operator description is `docs/release/config-contract.md`.

## Acceptance criteria

- **TC-04-007-AC1:** Login, reset, resend, and invite throttles are enforced across processes, and the 429 responses above include `Retry-After`.
- **TC-04-007-AC2:** Forgot-password responses do not reveal whether an email exists, including under the rate limit. The window expires; it does not permanently disable recovery.
