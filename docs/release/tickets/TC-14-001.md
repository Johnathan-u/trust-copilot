## Behavior

The web app keeps CSS custom properties plus Tailwind. Dark remains the default theme so existing screens stay on the navy product palette. A semantic light theme overrides the same `--tc-*` names when `html[data-theme="light"]` is set.

Coordinator decision, after the master merge: keep dark as the default. There is no product change that switches the default to light.

Shared type, spacing, focus, status and disabled tokens are documented in `docs/design/tokens.md` and locked by `apps/web/lib/design-tokens.ts`. Button, Input, Card, Toast, TagChip, EmptyState, Modal, Sidebar and the onboarding error state consume those tokens. The public showcase at `/design-tokens` renders both themes for contrast, focus and viewport checks.

`formatApiErrorDetail` is unchanged. `apiErrorPresentation()` adds a `danger` status for success-path formatting of failure and denial payloads. It does not persist data and does not interpolate secret fields.

## Ambiguities resolved

- The product spec suggests system sans, slate surfaces and a teal primary. The app already shipped a dark indigo theme. Dark keeps those colors. Light uses slate surfaces and teal `#0f766e`.
- Coordinator decision: keep Inter only as a self-hosted face. `next/font/local` loads the OFL variable files in `apps/web/app/fonts`, with a system-font fallback stack. There is no `next/font/google` import and no stylesheet request to a third-party font host. The static backlog page no longer imports a hosted font.
- White labels failed 4.5:1 on the previous bright primary and danger fills. Filled controls now use `--tc-primary-solid` and `--tc-danger-solid`.
- Decorative glow alphas were lowered so text tokens clear 4.5:1 on the lightest composited body pixel. This softens the dark page glow.
- Disabled text is held to 3:1, not 4.5:1, because WCAG 1.4.3 exempts inactive components.
- `--tc-border` stays a low-contrast hairline. Identifiable controls use `--tc-border-strong`.
- Card radius stays 18px. The 4px scale applies to padding, margin and gap.
- The minimum target is 24px (AA), not the 44px AAA size.
- Active navigation background is checked for the active label color only.
- Glass panel translucency is kept. The unit test composites it over both glows.
- The showcase sets `data-theme` on `<html>` before paint. An invalid `theme` query leaves the default dark theme.
