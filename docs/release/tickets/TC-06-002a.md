## Defect and repair

An authenticated workspace-A caller could request `/api/export-pack/evidence?questionnaire_id=<workspace-B-ID>` and receive B's document IDs, filenames, upload dates and citation counts. The cover and summary endpoints correctly returned 404 for the same foreign questionnaire. An owned questionnaire with persisted foreign document references also exposed foreign document metadata through both the evidence endpoint and full export pack.

`generate_evidence_bundle` now authorizes the questionnaire's workspace before traversing its questions and answers. Missing and foreign questionnaires raise the same existing `Questionnaire not found` error, translated to the same 404 response by the unchanged route. The full pack, cover and summary retain their existing response structure and authorization behavior.

Stored citation JSON grants no authority. Only positive integer `document_id` values within the existing database integer range are eligible for resolution. Booleans, coerced strings/floats, missing identities, malformed JSON and unknown IDs do not count as authorized references. A document is resolved only in the caller's current workspace. The manifest's distinct document count and repeated citation count both derive from those resolved references, so a filtered foreign reference cannot remain visible through an aggregate. Valid repeated citations still count separately. Invalid entries do not prevent later valid entries from being processed.

The existing behavior for legitimate same-workspace references is preserved, including archived document metadata. This child changes tenant authorization, not archive retention or role policy. It does not add chunk-only reference reconstruction, new response fields, new authentication/role guards, migrations or dependencies. The route's existing `require_session` contract remains unchanged.

## Verification

The new `tests/release/test_authorization_core_exports.py` contains 58 cases: 29 SQLite local controls and the same 29 migrated PostgreSQL acceptance cases. Each mounts the real export-pack router and service and uses real signing, stored users, memberships and session rows. Only the database dependency is injected. No authentication, membership, permission, document query or service response is mocked.

Coverage includes all four export-pack endpoints; the existing admin/editor/reviewer access; unauthenticated denial; identical foreign/missing questionnaire errors; same-workspace output preservation; duplicate, mixed, unknown and malformed references; and a document that has moved to another workspace. Every GET compares full rows across the relevant domain and authentication tables. The fixture records each inserted ID, deletes only those exact owned rows in FK-safe order, then verifies every original full row and count. SQLite foreign keys remain enabled. No pre-existing row, constraint or sequence is changed for setup/cleanup. Connections close even if a cleanup assertion fails.
