# TC-02-001 — Isolate test collection from live services

**Epic:** E02 Toolchain and CI · **Baseline:** `c20f949161ac12a619b396d30904448ffd74d532` · **Branch:** `tc/platform/TC-02-001`
**Evidence:** [`artifacts/acceptance/TC-02-001/`](../../../artifacts/acceptance/TC-02-001/README.md)
**Verification:** `cd apps/api && python -m pytest tests/release/test_safe_collection.py -q` → 26 passed.

## Problem at baseline

* `pytest --collect-only` in `apps/api` exited 2: `tests/test_alerts_api.py` and `tests/test_coverage_api.py`
  issued HTTP requests to `localhost:8000` **at import time** (4 socket connects recorded).
* Thirteen ad-hoc live scripts lived in `apps/api/tests/` (some matched `test_*.py`), several with a checked-in
  session-signing secret ("[REDACTED hardcoded session secret]", sha256 `9368da37…d6c8`) used to forge admin cookies,
  and one with a personal e-mail address.
* `tests/conftest.py` loaded the repo-root `.env` and exported its real `OPENAI_API_KEY` into the test process;
  `app/worker.py` also called `load_dotenv` on import. Two tests only passed with that real key, and
  `test_alerting_verification.py` made real outbound calls to `api.openai.com`.
* No pytest marker taxonomy, no `testpaths`, and `playwright.config.ts` accepted any `API_UPSTREAM`.

## Behaviour after this ticket

### Collection / import safety (AC1)
* `apps/api/tests/_safety.py` (imported first by `conftest.py`):
  * `TRUST_COPILOT_TESTING=1`, then **scrubs provider credentials** from `os.environ` (OpenAI, Anthropic, Stripe,
    OAuth/OIDC/ID.me secrets, SMTP, Sentry DSN, AWS, Slack, Gmail, `GOOGLE_APPLICATION_CREDENTIALS`, `REDIS_URL`).
    Opt-out only with `TC_ALLOW_PROVIDER_TESTS=1`.
  * **Validates the test database URL**: `postgresql` scheme, local host (loopback, `localhost`, `postgres`),
    database name ending in `_test`. Override with `TC_TEST_DATABASE_URL`; anything else raises
    `UnsafeTestTargetError` before any engine is created. Same check for the S3 endpoint (loopback/`minio`).
  * **Network guard**: patches `socket.connect`, `connect_ex` and `getaddrinfo`; only loopback, compose service
    names and `TC_TEST_ALLOWED_HOSTS` (single-label local names only) are allowed. Blocked attempts raise
    `NetworkAccessBlocked` (a `ConnectionRefusedError`). Any blocked attempt during **import/collection** aborts
    the session with a `UsageError`; attempts during test run are listed in the terminal summary.
* `conftest.py` no longer reads any `.env`; `app/worker.py` skips `load_dotenv` when `TRUST_COPILOT_TESTING=1`.
* Tests that only need "a key is configured" use the `synthetic_openai_key` fixture (fake value, client mocked).
* `pyproject.toml`: `testpaths=["tests"]`, `python_files=["test_*.py"]`, `norecursedirs` includes `scripts`,
  `alembic`, `app`, `fixtures`; `--strict-markers`.
* `apps/web/playwright.config.ts` throws `Refusing to run E2E: API_UPSTREAM=… is not a local host` unless the
  upstream is `localhost`, `127.0.0.1`, `[::1]` or the compose `api` service.
* CI (`.github/workflows/ci.yml`) gains a **Safe test collection** step (`pytest --collect-only -q` +
  the release test) before the backend test step.

### Marker taxonomy (AC2)

| Marker | Meaning | Default |
|---|---|---|
| `unit` | No DB, no ASGI app, no network. Must pass with Postgres down. | runs |
| `integration` | Uses local Postgres/MinIO via `client`, `db_session`, `test_workspace`, `_ensure_test_data`, or module references `SessionLocal`/`TestClient`/`create_engine`/`app.main`/`get_db`. | runs |
| `provider` | Real third-party call (OpenAI, Stripe, …). | **skipped** unless `TC_ALLOW_PROVIDER_TESTS=1` |
| `live_stack` | Needs a running local API/worker/Caddy. | **skipped** unless `TC_LIVE_STACK_TESTS=1` |
| `external_data` | Needs a dataset that is not checked in. | skips with reason |

Unmarked tests are auto-classified `unit`/`integration` by the rule above (explicit markers win).
Counts at branch head: 239 unit, 1075 integration, 0 provider, 0 live_stack, 1 external_data module.
`pytest -m unit` passes (239 passed, 1 skipped) with the DB URL pointed at a closed port.

## Running tests locally

```bash
cd apps/api
# default DB: postgresql://postgres:postgres@localhost:5432/trustcopilot_test (docker compose postgres)
export TC_TEST_DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:55432/trustcopilot_test   # optional
python -m pytest -q                 # unit + integration
python -m pytest -m unit -q         # no DB needed
TC_ALLOW_PROVIDER_TESTS=1 python -m pytest -m provider   # deliberate, paid; never in CI
```

## Decisions / ambiguities (resolved conservatively)
1. **Move vs. ignore** unsafe scripts: moved out of `tests/` (not `collect_ignore`) so no pattern change can re-collect them.
2. **Leaked session secret** remains in git history: must be **rotated** in every environment (owner: secret inventory ticket). Not reproduced anywhere.
3. `docker-compose.prod.yml` contains a hardcoded Postgres password — out of scope (secret-inventory ticket); not reproduced.
4. Guard limits: libpq (psycopg2) and subprocesses (alembic) bypass Python sockets; they are constrained by DB URL validation instead.
5. Marker auto-classification is a heuristic and errs toward `integration`.
6. `test_alerting_verification.py::test_openai_failure_logs_ALERT_OPENAI_FAILURE` previously reached `api.openai.com`; now blocked by the guard and still passes. Left `integration`; should be fully mocked in a follow-up.
7. Default `localhost:5432` may be an unrelated Postgres on a developer machine; the `_test` suffix check and `TC_TEST_DATABASE_URL` mitigate this.
8. Other repo `scripts/*.py` still load `.env`; none are imported by tests.
9. API Dockerfile copies `apps/api` (including `tests/` and `scripts/manual_live/`) into the image; no secrets remain there, image slimming is out of scope.
10. Dependency locking (SQLAlchemy 2.1 → psycopg3 default) belongs to TC-02-002; evidence ran with SQLAlchemy 2.0.55.
11. Reviewer sign-off (DoD) must come from someone other than the implementer.
