# TC-21-007 Reproducible framework coverage denominators

**Status:** implemented. Framework catalogs stay **BLOCKED** pending **TC-01-007**. No framework requirement text was added. No migration.

The route stays mounted at `/api/compliance-coverage`. `GET` does not write and stays on review.

## Denominator

`control_coverage` uses schema `compliance-coverage-controls/v1`. The existing question fields (`kpi`, `framework_coverage`, and the rest) are unchanged.

The numerator is the count of distinct applicable controls with qualifying evidence. Qualification is the TC-21-003 rule: approved, same workspace, not expired, and not tied to a deleted document. A verified label without that evidence is not qualified.

The denominator is the distinct applicable controls. Disabled controls, unknown framework references, and blocked catalogs are left out, and each of those is a denominator change in `explanations`. Stale, gap, and failed controls stay in the denominator and out of the numerator. A check error on one control does not drop the others.

Explanations name `state`, `rule`, `effect`, `denominator_changed`, and `framework_id`. They do not include catalog text or an evidence id from another workspace.

`control_id` is optional. When it is present and belongs to this workspace, the totals are the same as the unscoped read. A missing id and an id from another workspace return the same 404.

Nothing is stored. A second read, including from a new database session, returns the same `control_coverage` object.

## Ambiguities

- There is no disabled status in the control API. A row whose `lifecycle` or `status` is `disabled` is left out of the denominator and explained.
- A custom control with no framework template is applicable. A template that is missing, or whose framework row is missing, is unknown and left out.
- Blocked catalogs are reported as `blocked` with `framework_id`. They are not skipped silently and their names are not copied into `control_coverage`.
- A present `control_id` does not narrow the denominator. It only rejects a missing or foreign id.
- The question KPIs are still answer counts. The control denominator is the versioned `control_coverage` object.
- The web page and the AI governance coverage section both parse that object. A wrong schema version fails the load.
