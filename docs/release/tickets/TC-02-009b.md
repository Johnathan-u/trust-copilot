## Behaviour

`docs/ops/ci-evidence.md` states the 14-day artifact retention, the Actions log retention (repository setting, GitHub default 90 days; this workflow does not delete logs), where the evidence block and the uploads live, and that no Pages or deploy workflow can mark a failed CI run successful.

`apps/api/tests/release/test_ci_evidence.py` parses the workflow files. It checks that both jobs print the SHA, the image digest or `image: none`, the command, and the totals; that every `actions/upload-artifact` step sets `retention-days: 14`; that secret-bearing values are not echoed without a mask; that Playwright trace and report redaction is configured; and that a `workflow_run` Pages deploy must require `github.event.workflow_run.conclusion == 'success'`. `if: success()` is not enough. Negative tests feed a workflow missing the SHA line, missing retention, or echoing a generated password, and a Pages workflow that ignores the conclusion. Nothing is skipped. The command from `apps/api` is `python -m pytest tests/release/test_ci_evidence.py -q`.

`docs/release/tickets/TC-02-009.md` maps AC1, AC2, and DoD1–DoD5 to file and line.
