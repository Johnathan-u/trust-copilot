# Provider response streaming limit implementation plan

**Goal:** Enforce the existing 1 MiB Slack/Gmail response limit before consuming an entire oversized response.

**Architecture:** Read provider responses through the HTTP client's streaming interface, count decoded bytes before retaining them, and close the stream on every exit. Translate an oversized response into the existing nonretryable `response_too_large` result. No data schema, API route, dependency, or provider permission changes.

**Tech stack:** Python, the existing HTTPX client and pytest.

**Spec:** [Coordinator assignment and acceptance](https://github.com/Johnathan-u/trust-copilot/issues/85#issuecomment-6503119958).

## Constraints and review focus

- Change only the allocated transport/retry implementation, new regression tests, and ticket evidence.
- No live provider calls, paid accounts, new dependencies, or migrations.
- Preserve the existing 1,048,576-byte inclusive limit and nonretryable failure contract.
- Missing or misleading Content-Length cannot bypass the decoded-byte limit.
- Compressed responses count decoded bytes, and small compressed responses stay readable.
- Stream resources close on success, oversize, and read failure.
- Failure does not retain or expose the rejected response body or retry a provider side effect.

## Independent review

The fresh reviewer ran the 15 new regressions and reported no critical or important findings. A minor limitation remains: reconstructing the buffered response does not preserve HTTPX elapsed/download-counter metadata, which no existing provider caller consumes. This does not change provider response bodies, status, or headers. The reviewer separately verified closure on malformed gzip.

Ruling: use the existing HTTPX decoder and count its yielded decoded bytes rather than introducing a new decompressor. The assigned contract is early stream termination and bounded retained response content; a strict decompression-memory ceiling would require separately scoped work. Cost: one transport chunk can temporarily expand beyond the retained-body limit.
