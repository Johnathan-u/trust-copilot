`verify-code` previously returned success for a verified account before checking
the supplied proof. Wrong codes disclosed verification state, and consumed codes
still returned success. The existing already-verified response now requires a
matching, unexpired, user-bound token and consumes it first. Existing invalid and
expired responses, token deletion, normal verification audit, normalization and
successful response wording are retained. Replays receive `400 Invalid code`.

`forgot-password` previously counted attempts only for existing accounts. Requests
for unknown accounts could avoid the same IP limit indefinitely. Attempt recording
now precedes account lookup, after the existing limiter check. The ten-attempt,
sixty-second policy, generic success, cooldown error, token replacement, audit and
email behavior remain unchanged.

The new matrix runs the actual HTTP routes with persisted users, verification and
reset tokens, sessions and audits. SQLite enforces foreign keys; matching PostgreSQL
cases use the existing migrated schema. No authorization or token/limiter method is
mocked. Controlled clocks make expiry and cooldown deterministic. The actual email
builder and background thread deliver only to a local outbox. This proves the
control path, not external mail delivery.

Fresh TDD reproduction on the base: 10 failures and 12 passing controls. After the
two bounded repairs: all 22 SQLite cases pass; the same 22 PostgreSQL cases remain
mandatory in CI. Denials assert no SQL writes or full-row changes, positive cases
assert exact token/audit effects and preserve unrelated rows, and fixture cleanup
deletes only recorded owned IDs before comparing the original full rows.

See [verification.json](../../../artifacts/acceptance/TC-04-007a/verification.json)
for tested source identities, commands, outcomes and limitations. Only
`verify_code` and `forgot_password` change. No migration, shared limiter, session,
provider or frontend change is included. Timing equalization, distributed throttle
qualification and the remaining login/resend/invite abuse contract remain with
TC-04-007; this child does not complete the parent.
