## Behaviour
- **XLSX answer cells** (`xlsx_writer.place_answers_into_workbook` and `write_answers_to_sheet`)
  are always stored as string cells (`t="inlineStr"`) and never as `<f>`.
  - Values that look like formulas also get Excel's `quotePrefix` flag, which is the hidden
    leading apostrophe. Re-editing the cell in Excel therefore keeps it literal.
  - The visible text is never changed.
  - A value counts as formula-like when it starts with `=`, `+`, `-`, `@`, tab, CR or a
    full-width `＝＋－＠`, ignoring leading spaces.
  - Numeric-looking answers such as `"123"` stay text.
- **Original formulas are preserved.** The workbook is still loaded with `data_only=False`.
  - Formulas outside the answer cells round-trip unchanged.
  - If the computed answer target already holds a formula (normal, array or data-table formula),
    that cell is **not overwritten**. The placement is skipped and logged as
    `EXPORT: skipped answer placement; target holds original formula`. It is also appended to the
    optional `skipped=[...]` list on `place_answers_into_workbook` and
    `create_export_from_questionnaire`.
- **Formats are not copied blindly.**
  - A target cell that already has its own style keeps it.
  - An unstyled target receives only the question cell's font, border, fill and alignment
    (the EXP-04 visual formatting).
  - `number_format` and `protection` are never copied.
- **CSV fallback** (`fallback_export.create_fallback_pack_csv`)
  - Formula-like question and answer values are prefixed with `'`, following the OWASP
    CSV-injection guidance.
  - It now returns UTF-8 bytes. On baseline it raised `TypeError` because `csv.writer` was used
    on a `BytesIO`.
- **DOCX** (in-place and fallback) writes Word text runs, which cannot execute. No change was
  needed there.

## Configuration
There is no new configuration. `EXPORT_ANSWER_COL_OFFSET` is unchanged. Explicit target mapping
belongs to TC-09-002 and TC-13-001.

## Operator / help note
If an export is missing an answer and the worker log shows the skip message above, the template's
answer cell contains a formula. Either clear that cell in the source template or map the answer
to a different cell once explicit targets are available (TC-13-001).
