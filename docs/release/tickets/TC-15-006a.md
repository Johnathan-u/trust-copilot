## Problem

The forgot-password page copies an http `reset_url` into the DOM. That URL contains the raw reset token. The flag is off in production and defaults off, and any process whose `APP_ENV` is not production returns that credential once the flag is true. The known-address 429 split is TC-04-007a. This child does not repeat it. The verification report proposed P0. Claude's review tick on #85 comment 7039897301 rules this child P1, not P0.

## Acceptance criteria

1. Stop returning the raw reset token from forgot-password, and stop rendering `reset_url` on the page.
2. Do not take on the known-address 429 split. That hole is TC-04-007a.
3. Document the behaviour in this file.
