## How to operate

- Local: `nvm use` (reads `apps/web/.nvmrc`), then `cd apps/web && npm ci --ignore-scripts`.
  With `engine-strict`, `npm ci` refuses Node < 24.11 or ≥ 25.
- Adding/upgrading a package: `npm install --ignore-scripts <pkg>@<exact>`; `save-exact` keeps the pin.
  Run `npm run typecheck && npm run build && npm audit` and
  `cd apps/api && python -m pytest tests/release/test_web_lock.py -q`.
- Production image: `docker build -f apps/web/Dockerfile --target production .` — start command is
  `node server.js` (env `PORT`, `HOSTNAME`); `API_UPSTREAM` is still read at runtime by
  `app/api/[[...path]]/route.ts`.
- Bumping Node: change `.nvmrc`, `NODE_IMAGE` (tag **and** digest) and, for a new major, `engines`
  plus `SUPPORTED_NODE_MAJOR` in the release test.

## Release test

`apps/api/tests/release/test_web_lock.py` (static, offline, deterministic, 18 tests): exact pins;
lock matches pins, registry-only sources with sha512 integrity; Next/React on supported patched
lines; Node single-sourced (.nvmrc = Docker = CI = engines); CI uses `npm ci --ignore-scripts`,
typecheck, build, audit; only allow-listed install scripts; production stage ships standalone output
only, non-root, no npm, no dev server; plus denial cases on synthetic bad inputs (range specs, EOL
Next/Node, drifted/untrusted lock, the baseline Dockerfile, unpinned base image). On baseline c20f949
it fails 11/18, on this branch 18/18 pass.

## Known limits / follow-ups

- `middleware.ts` builds with a Next 16 deprecation warning ("use proxy"). Still supported in 16.x;
  rename deferred to avoid touching auth routing in a dependency ticket.
- Rewrites in `next.config.js` are evaluated at build time under `output: 'standalone'`. `/api/*` is
  served by the runtime route handler, so the rewrite is shadowed and behaviour is unchanged.
- Debian OS packages carry unfixed HIGH CVEs (no fixed package available, not reachable) — see the
  evidence triage table; re-scan on each base bump.
- Root `package-lock.json` (dev-only `concurrently` → `shell-quote` critical) is outside apps/web and
  not shipped; left for a follow-up.
- Reviewer sign-off (DoD) is pending.
