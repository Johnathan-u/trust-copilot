# TC-06-003g — Control timeline evidence authorization

Parent: TC-06-003; related frozen contract: TC-22-003 AC2. Estimate: 3 points.
Claim: #85/6516966183. Base: `d4f8f38e482532e14d08c28ba0baf6ccc0002a06`.
Status: local controls pass; independent review and PostgreSQL CI pending.

An authorized control's timeline loaded linked evidence by ID alone. A
cross-workspace link, or evidence moved to another workspace after linking,
exposed that evidence's ID, title and timestamp. It also affected event counts,
ordering and the limited result. The control itself was already tenant-scoped.

The service now requires linked evidence to belong to the authenticated workspace
before constructing an event. No route, schema, permission, snapshot, lifecycle or
response contract changes. Own evidence, state changes, review/verification events,
existing snapshot/event limit semantics and neutral parent 404s are preserved.

Acceptance coverage:

- Real stored-session HTTP against SQLite and migrated PostgreSQL: mixed and
  foreign-only links, evidence moved away, real deleted-evidence cascade, and
  exact own-event projections at limits 1, 2 and 50.
- Foreign, moved, deleted and missing controls retain the existing 404 before
  child-object queries; unchanged current session-only read permission is tested.
- Anonymous, expired, revoked, wrong-user SID, suspended, removed and missing
  workspace authority is rejected before timeline object queries.
- All GETs preserve complete-row hashes across 13 tables and execute SELECTs
  only. Fixture cleanup deletes exact owned IDs and restores the baseline.
- Any PostgreSQL FK/check rejection of a fixture cross-link or parent move is
  tested transactionally and reported as database protection, separately from
  successful construction followed by HTTP filtering. No constraint is bypassed.

Initial tests reproduced four SQLite failures. With the single predicate added,
all 25 local cases pass; 50 cases collect. PostgreSQL is unavailable locally and
must execute in CI. See `artifacts/acceptance/TC-06-003g/` for verification.

This does not close all controls authorization, TC-06-003, timeline persistence
and replay requirements, or owner/viewer policy. Control engine, proof graph,
credentials, answers, authentication, shared references and migrations are outside
this child. No provider, model or object-storage calls were made.
