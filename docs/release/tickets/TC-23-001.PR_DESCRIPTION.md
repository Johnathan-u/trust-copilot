## Migration

`tc23001_deal_types` revises `tc10001_job_leases` (17-character revision id). An earlier note said to parent on `tc21006_gap_evaluation` until push. That revision already has descendants (`bug018b_gap_status_checks` and later), so a second parent would fork alembic. This local migration follows the current head instead.

Exact float amounts become `numeric(18,2)`. A float that is not the float8 image of `round(value, 2)` is stored in `tc23001_deal_amount_hold` with its original text and the reason `float value is not exactly representable as numeric(18,2)`, and the deal amount is null. Downgrade restores that text. Re-upgrade holds it again. Expected close is backfilled from `close_date::date`. New columns that did not exist before are not invented on re-upgrade.
