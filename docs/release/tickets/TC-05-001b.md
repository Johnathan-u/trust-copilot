## Problem

Provider login with an enabled factor redirects to `/login?mfa_token=...`. The sign-in page removes the token from the address bar after reading it. The token is a five-minute single-use secret, and it can still appear in that redirect's browser history entry and in access logs.

## Acceptance criteria

1. Move the MFA token out of the redirect URL query string. Use a URL fragment or a short-lived cookie.
2. The token is not written to the request query, access logs, or the browser history entry for the login redirect.
3. The existing TOTP and recovery verify still complete the challenge. Document the behaviour in this file.
