## Gaps
1. Exclude ineligible sources at retrieval time. Keyword and semantic search should drop chunks whose document is soft-deleted, not `indexed`, or superseded. Soft delete (`documents.py:338-340`) should remove or tombstone those chunks and bump the corpus version. The docstring on `bump_corpus_version` already says to call it after delete (`apps/api/app/core/corpus_version.py:37-38`); the delete route does not.
2. Put corpus version, prompt version, and model id on the answer cache key (`answer_cache.py:13-17`), and invalidate that cache when the corpus version bumps (`index_service.py:202-210` currently invalidates retrieval cache only). A hit whose stored version is stale should return `None`, as `retrieval_cache.get` does at `retrieval_cache.py:41-42`.
3. Apply the caller's permission policy when searching, not only the workspace id. A document the principal cannot read should not appear in context or citations even when it shares the workspace.
4. Add `apps/api/tests/release/test_retrieval_isolation.py`, `artifacts/acceptance/TC-08-004/`, and `docs/release/tickets/TC-08-004.md`. The test should set the same question in two workspaces, assert the caches and the citations do not cross, bump the corpus version, and assert both caches miss. Tighten `test_answer_pipeline.py:116` so a stale retrieval hit must be `None`. The backlog command is `python -m pytest tests/release/test_retrieval_isolation.py -q`.
