## Gaps
1. Do not leave a retrievable corpus when embedding fails or is incomplete. Commit `indexed` only when every chunk has a vector of `EMBEDDING_DIM`. On a `None` batch or a raised embed call, roll back the chunk insert instead of committing null-embedding rows at `index_service.py:163-168`. Keyword search (`retrieval.py:235-256`) should not return chunks whose document is not `indexed` or whose embedding is null.
2. Reindex when the embedding model or dimension changes. Persist the model id and dimension with the chunks. A mismatch should enqueue one new complete version, not skip because `status == "indexed"` (`worker.py:567-575`) and not drop the bad vectors with `continue` (`index_service.py:151-154`).
3. Add `apps/api/tests/release/test_index_atomicity.py`, `artifacts/acceptance/TC-08-003/`, and `docs/release/tickets/TC-08-003.md`. The test should cover an all-`None` `embed_texts`, a mixed batch, a dimension `ValueError`, and a retry that leaves exactly one complete version that both semantic and keyword search can see. The backlog command is `python -m pytest tests/release/test_index_atomicity.py -q`.
