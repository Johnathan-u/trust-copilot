## Gaps
1. **TC-15-006a (P0).** Live reset-token leak on the flag path. The page copies an http `reset_url` into the DOM (`page.tsx:34-39`, `:67-71`). That URL contains the raw reset token (`auth.py:792-794`). `_dev_reset_url_enabled` returns false when `is_production_env()` is true (`auth.py:565-566`), and the flag defaults off (`:567-568`). This run's passing test still reads the token from `reset_url` when the flag is set (`test_identity_tokens.py:200-205`, `:153-157`). Any process whose `APP_ENV` is not production, including the default `development` (`config.py:273`), returns that credential to the caller once the flag is true. Stop returning the token and stop rendering it. The known-address 429 split is TC-04-007a. This child does not repeat it.
