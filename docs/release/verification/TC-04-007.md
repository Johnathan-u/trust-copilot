## Gaps
1. **TC-04-007a (P0).** Live enumeration side channel. `forgot_password` counts `reset:ip` only after a user row is found (`auth.py:781-787`). Eleven requests for a known address become 429. The same requests for an unknown address stay 200 with the generic message. Count every attempt before the lookup, and keep the 200 body the same. Closed unmerged #161 already used the id TC-04-007a for this gap. It is not on master. Priority is P0 because the parent is P0 (`docs/planning/tickets/TC-04-007.md:3`) and the status split is live on the default limiter.
2. **TC-04-007b (P0).** Share the limiter across processes. The default is per-process memory, and production without `REDIS_URL` still uses it (`rate_limit.py:25-28`, `:103-111`). Put `Retry-After` on the login, reset, resend, and invite 429 responses. Limit invite creation (`members.py:160-169`). Add `apps/api/tests/release/test_auth_rate_limits.py` and `docs/release/tickets/TC-04-007.md`. The backlog command is `python -m pytest tests/release/test_auth_rate_limits.py -q`.
