## Localhost fallback
Not test-only. Before this change, a cookie state-changing request with no Origin and no Referer was allowed when the request host was `localhost`, `127.0.0.1`, `::1`, `::ffff:127.0.0.1`, or `testserver`. The host is `request.url.hostname` (`apps/api/app/main.py:331`), the Host header. Production compose sets `APP_ENV=production` (`docker-compose.prod.yml:67`). The API is on `trustnet` at port 8000 (`:86-87`). A direct peer can send `Host: localhost`. Caddy's public path sets Host to `{hostport}` (`infra/caddy/Caddyfile.production:56`), so a browser request for `trustcopilot.app` does not take this path. The production process still had it.

It is closed. `CSRFMiddleware` passes `production=is_production_env()` (`main.py:336-349`). `is_production_env` is the existing `APP_ENV` check (`apps/api/app/core/session.py:64-78`). `is_csrf_safe` does not read the environment. When `production` is true the host fallback is false (`csrf.py:162-169`). Dev and test still allow it (`production` defaults false; `test_csrf_proxy.py:350-381` and `:173-198`). An allowed Origin, an allowed Referer, or a trusted-proxy forwarded origin still passes in production (`:384-416`).

This does not block MEETS. The path could apply on a production process. This SHA removes it. DoD5 is the item that blocks DONE.
