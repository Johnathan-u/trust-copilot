## Gaps
1. **Security.** Reject a state-changing cookie request when Origin is present and not in `trusted_origins`, before Referer or `X-Forwarded-*` is considered (`csrf.py:60-77`). Accept `X-Forwarded-Host` only from a configured trusted proxy. Add a test that Origin `https://evil.example.com` plus `X-Forwarded-Host` of an allowed host is false.
