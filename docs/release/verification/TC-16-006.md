### What stops a flag from gating a control

`is_security_sensitive_flag` (`feature_flags.py:87`) matches a dot-segment to
`SECURITY_FLAG_TOKENS` (`feature_flags.py:63`): equal, or `<token>_`.
`is_enabled` raises `SecurityFlagError` before any read (`feature_flags.py:166`).
`set_flag` raises before any write or audit (`feature_flags.py:232`).
`seed_defaults` skips the name (`feature_flags.py:305`). `GET` returns 400
(`routes/feature_flags.py:44`). `PATCH` returns 400 (`routes/feature_flags.py:71`)
and does not call `set_flag`, so there is no audit row.
