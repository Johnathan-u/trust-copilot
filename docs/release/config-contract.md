# Configuration contract (TC-03-001)

Source of truth: `apps/api/app/core/config_contract.py`. The table between the markers is generated by
`cd apps/api && python -m app.core.config_contract markdown`; `tests/release/test_config_contract.py` fails if it drifts.

* **Production** (`APP_ENV=production`): `required` variables must be present and valid; `forbidden` variables must be
  unset; `conditional` variables are checked whenever they are visible to the process (compose `env_file`).
  Any violation stops the API (lifespan, before the DB is contacted), the worker (`app.worker.main`), Alembic
  (`alembic/env.py`) and the container entrypoint (`python -m app.core.config_contract check`, exit 2).
* Credentials are refused when unset, shorter than 16 characters (SESSION_SECRET: 32), low-variety, a placeholder,
  or a publicly known vendor/tutorial default (`KNOWN_DEFAULT_CREDENTIALS`) — this covers every value in
  `.env.example` and every dev default in `docker-compose.yml`, which the release test checks automatically.
* Error messages list variable names and reasons only, never values.
* **Non-production**: only malformed values that would crash `Settings()` and unknown `APP_ENV` values are fatal;
  everything else is reported as a warning.

## Owner-account / infrastructure prerequisites

| Prerequisite | Variables | Validation |
|---|---|---|
| Public hostname with DNS + TLS (Caddy ACME, `infra/caddy/Caddyfile.production`) | APP_BASE_URL, FRONTEND_URL, TRUSTED_ORIGINS | https, non-localhost |
| PostgreSQL 16 + pgvector with a generated password | DATABASE_URL, POSTGRES_USER, POSTGRES_PASSWORD | explicit DSN, strong non-default password |
| Private S3-compatible storage with dedicated keys | S3_ENDPOINT, S3_ACCESS_KEY, S3_SECRET_KEY, MINIO_ROOT_USER, MINIO_ROOT_PASSWORD | required, non-default |
| Model provider account | OPENAI_API_KEY | required, not placeholder |
| SMTP relay account | SMTP_HOST, SMTP_FROM (+ SMTP_USER/SMTP_PASSWORD) | required |
| Optional identity providers / billing | OAUTH_*, OIDC_*, IDME_*, STRIPE_* | id/secret pairs complete; webhook secret with Stripe key |
| Initial owner account | — (no seed in production) | demo/QA/E2E seed scripts refuse `APP_ENV=production` with no override |
